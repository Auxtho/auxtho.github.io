How to read the result

  1. 1 Locate the record binding checksum from the last page of the exported artifact or QR link.
  2. 2 Run the record check here. For a digital PDF check, select the PDF so the browser can compute its SHA-256 digest without uploading the file contents; the API compares only that submitted digest with the issued record.
  3. 3 Distinguish a record match from a submitted digest match. A digest match does not mean the API received or inspected the selected file bytes. Stored cryptographic metadata appears only when the artifact response contains a complete, consistent field set, and this browser does not cryptographically revalidate it.

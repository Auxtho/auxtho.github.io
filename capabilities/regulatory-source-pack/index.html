Capability 02 / Regulatory Source Pack

Keep current, supporting, and proposed sources distinct.

Auxtho records each approved public source's exact version and review role. If the recorded source set becomes stale, incomplete, unclear, or changes, it cannot support the report until another review is completed.

A document can remain visible for inspection without being allowed to support a current release claim.

Inspect the source rolesOpen the frozen source proof

The job in plain language

A financial report uses more than one kind of regulatory material.

A current Notice, a supporting FAQ, and a closed consultation may all be relevant to review, but they do not carry the same role.

Document or job

A regulatory source set for one workflow

The frozen example is used to review selected claims in a Singapore financial assurance report.

What Auxtho performs

Keeps each source's version and role clear

Auxtho records whether each source is current, supporting, or proposed, whether it may support the report, and which reviewed claims could be affected by a change.

What a person decides

Whether a new pack version becomes active

An accountable reviewer activates the exact version after a separately authorized preparation and review step.

What appears on screen

Lifecycle status and each source role

The App shows ACTIVE or re-review state and the role of every exact source in the pack.

What remains

An exact pack identity and lifecycle history

The prior pack, decisions, source identities, transition events, and impact inventory remain available for reconstruction.

Actual product screens

Read the lifecycle and source roles without opening internal mechanics.

The first panel shows the workspace lifecycle readback. The second shows the exact public source inventory and distinct eligibility roles.

Lifecycle path

Change the source set without carrying the old approval forward.

01Bind exact sources

Issuer, URL, bytes, SHA-256, page count, status, role, and eligibility form the source identity.

02Record the active version

The workspace activates one exact version under separate preparation and review roles.

03Detect a recorded change

A deterministic diff lists changed fields and the claims and prior releases affected.

04Require re-review

Stale, incomplete, ambiguous, or update-pending state stops the pack from supporting release.

05Activate a new exact version

The new decision does not rewrite the old pack or the decisions that used it.

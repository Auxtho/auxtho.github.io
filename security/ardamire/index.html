What the controlled tests checked

  • Related signals changed the next action. Different authentication anomaly signals accumulated within a bounded context. A challenged operator could still read the permitted authentication state, but a state-changing request required additional verification.
  • A weak signal did not immediately stop the workflow. A single weak missing-export signal did not trigger quarantine. Repeated signals for the same object led to an artifact/export hold, rather than a whole-run hold.

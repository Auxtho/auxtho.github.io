What the work looks like

Choose the goal and permitted resources. Start the implemented workflow. Inspect the returned result and its record

WHY IT MATTERS

The device in your hands does not need to hold every model or perform every task. Use an approved computer for the work it can handle, receive the result where you started, and see which resources produced it

HOW IT CONNECTS

Moirion provides the journal and answer interface; Agent Runner handles delegated work and review. Metdol has demonstrated execution, status and result paths with both. Its local resource-fit advisory is implemented; connecting that advisory and execution transport to Auxtho's model-selection and invocation path remains in development

19 September 2026Real model execution across computers＋

Executed Gemma 3 27B through the integrated Windows path, then completed a real Mac→Windows model request over an authenticated private-LAN connection

Moirion’s Mac development app explicitly selected a Windows RTX 5090 and Gemma 3 27B, received the answer and displayed its machine and model

20 September 2026Source, model and tool produce a brief＋

A selected report, Gemma 3 27B and a registered validation tool produced a saved Markdown brief. The receipt links its source, model, defined checks and output

21 September 2026AgentRunner work delivered and verified＋

AgentRunner delivered a predefined helper task from Mac to Windows. The helper executed under Windows OS controls; AgentRunner independently verified the returned artifact and attached its evaluation for human review

23 September 2026Windows local cancellation and cleanup＋

A local Windows cancellation probe verified the fixed helper’s cancellation path and required cleanup. This is local cancellation evidence; cross-device AgentRunner cancellation remains a separate development gate

26 September 2026A lost acknowledgement, a recovered result＋

A real lost-acknowledgement recovery test reopened the work from a new process and recovered its result and evaluation. Retained Windows state independently confirmed one execution and one capability use
